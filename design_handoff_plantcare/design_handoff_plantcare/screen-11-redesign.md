# Экран 11 · «График ухода» — редизайн (вариант A · «Повестка дня»)

> Заменяет прежний матричный календарь. Источник: `design/screens-week-variants.jsx → WeekCalA`
> (он же экспортируется как `WeekCalendarScreen`, поэтому подставлен везде в прототипе).
> Этот документ самодостаточен — реализовать экран можно по нему одному.

---

## 1. Зачем переделали

Прежний экран 11 смешивал три метафоры в одном вьюпорте: горизонтальные прогресс‑бары по дням,
развёрнутую карточку «сегодня» и подсказку про экспорт в `.ics`. Получалось плотно и неясно,
куда смотреть. Новый экран строится на одной чёткой модели: **выбери день → увидь задачи этого дня**,
сгруппированные по времени суток. Это привычный «agenda»‑паттерн, который легко читается и
масштабируется на любое число растений.

Варианты B (матрица растения×дни) и C (лента‑таймлайн) остались в `screens-week-variants.jsx`
(`WeekCalB`, `WeekCalC`) как запасные направления — в продакшен не идут.

## 3. Компоненты подробно

### 3.1 Header
- Контейнер: `padding: 20px 22px 6px`, `flex`, `space-between`, `align-items: center`.
- Надзаголовок: `МАЙ 2026` — `11px / 700`, `letter-spacing: 0.06em`, `uppercase`, цвет `inkSoft`.
- Заголовок: «График ухода» — **Instrument Serif** `400 / 30px`, `line-height: 1.04`, цвет `ink`.
- Кнопка справа: иконка `calendar`, `40×40`, `radius 14`, `background surface`, `border 1px line`.

### 3.2 День‑селектор
- Горизонтальный ряд: `flex`, `gap: 7`, `padding: 14px 16px 4px`, `overflow-x: auto`.
- Каждая ячейка: `min-width: 46`, `flex: 1 0 auto`, `padding: 10px 0 8px`, `radius 18`, `text-align: center`.
  - **Невыбранный день:** `background surface`, `border 1px line`.
  - **Выбранный день** (сегодня = индекс 2 в прототипе): `background primary`, `border primary`, текст белый.
- Внутри ячейки:
  - День недели — `10px / 700`, `uppercase`, `letter-spacing 0.04em`. Невыбр. — `inkSoft`; выбр. — `rgba(255,255,255,0.8)`.
  - Число — **Instrument Serif** `22px`. Невыбр. — `ink`; выбр. — `#fff`.
  - **Точки нагрузки** — ряд `height: 6`, `gap: 2`, по центру:
    - `0` задач → символ `—` (`9px`, `inkMute` / на выбранном `rgba(255,255,255,0.7)`).
    - иначе `min(count, 3)` точек `5×5`, `radius 3`. Невыбр. — `leaf`; выбр. — `rgba(255,255,255,0.85)`.
- Счётчики нагрузки в прототипе: `[2, 3, 5, 1, 4, 2, 0]` (Пн…Вс).

### 3.3 Подзаголовок дня
- `flex`, `space-between`, `align-items: baseline`, `padding: 0 6px 16px`.
- Слева: «Среда, 13 мая» — `15px / 700`, `ink`.
- Справа: «1 из 5 готово» — `13px`, `inkSoft`.

### 3.4 Группа задач (`Group`)
Три группы: **Утро · 9:00**, **Вечер · 19:00**, **Сделано** (без времени).
- Заголовок группы: `flex`, `align-items: baseline`, `gap: 8`, `padding: 0 4px 10px`.
  - Лейбл — `12px / 700`, `uppercase`, `letter-spacing 0.06em`, `inkSoft`.
  - Время — `12px`, `inkMute`.
  - Линия‑филлер — `flex: 1`, `height: 1`, `background line`, сдвиг `translateY(-3px)`.
- Список строк: `flex column`, `gap: 8`.

### 3.5 Строка задачи (`Row`)
- Контейнер: `flex`, `align-items: center`, `gap: 12`, `padding: 10px 12px`, `radius 18`,
  `background surface`, `border 1px line`.
  - **Overdue:** рамка `terracotta` вместо `line`.
  - **Done (dim):** весь контейнер `opacity: 0.5`.
- Аватар растения: `44×44`, `radius 14`, `background surfaceWarm`, по центру SVG‑иллюстрация (`size 40`).
- Текст (flex: 1):
  - Имя растения — `15px / 700`. В done — `text-decoration: line-through`.
  - Подпись — `12px / 600`:
    - обычная: `«{Действие} · {Вид}»`, цвет `inkSoft`;
    - overdue: `«Просрочено · со вчера»`, цвет `terracotta`.
- Кнопка‑чек справа: `34×34`, `radius 12`, `flex-shrink: 0`:
  - **не выполнено:** `background <tint действия>`, внутри иконка действия, белая, `stroke 2`.
  - **выполнено (dim):** `background transparent`, `border 2px line`, иконка `check`, `inkMute`.

## 6. Поведение / состояния

- **Тап по дню** в селекторе → перерисовка списка задач выбранного дня; подзаголовок и счётчик обновляются.
- **Тап по кнопке‑чеку** в строке → `POST /api/v1/care-events` (idempotent `clientId`), строка переезжает в «Сделано» с зачёркиванием и dim. Оптимистично, с откатом по ошибке.
- **Overdue** определяется на клиенте: `nextDueAt < startOfToday` для задачи, попавшей в выбранный день.
- **Пустой день** (0 задач): показать дружелюбную заглушку («На этот день забот нет 🌿») вместо групп.
- **Группировка по времени суток** — клиентская, по `nextDueAt`/предпочтительному времени (нет в API).
  Утро `< 12:00`, вечер `≥ 12:00`; «Сделано» — события с `performedAt` за этот день.

## 7. API

```
GET /api/v1/calendar?from=YYYY-MM-DD&to=YYYY-MM-DD
→ Map<YYYY-MM-DD, TaskDto[]>   // максимум 60 дней
```
- Селектор недели запрашивает `from = понедельник`, `to = воскресенье`.
- Точки нагрузки = `tasks.length` по каждому дню (рисуем `min(n, 3)`).
- Отметка ухода: `POST /api/v1/care-events { clientId, plantId, type, performedAt, note? }`.
- Инвалидация после отметки: `['calendar', {from,to}]`, `['today']`, `['plant', id]`, `['plant', id, 'streak']`.

> Группировка по утро/вечер и поле «вид в подписи» формируются клиентом — серверного аналога нет.

## 8. RN‑заметки по переносу

- День‑селектор → горизонтальный `<ScrollView horizontal>` или `<FlatList horizontal>`.
- Список групп → секции в `<SectionList>` или просто `map` внутри `<ScrollView>` (объём небольшой).
- `overflow: auto` → `<ScrollView>`; `<button>` → `<Pressable>`.
- Линия‑филлер в заголовке группы со сдвигом `translateY(-3px)` — на RN проще `borderBottomWidth` у обёртки или отдельная `<View>` c `flex: 1, height: 1`.
- `opacity` строки done переносится 1‑в‑1; `line-through` → `textDecorationLine: 'line-through'`.
