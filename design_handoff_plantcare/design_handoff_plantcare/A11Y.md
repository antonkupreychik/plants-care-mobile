# A11Y.md — доступность и устойчивость к данным

> Как сделать PlantCare доступным и не сломать вёрстку на реальных данных.
> Визуальный референс корректного поведения — `design/Robustness.html` (обычно vs под нагрузкой).
> RN: `allowFontScaling`, `accessibilityLabel/Role`, `AccessibilityInfo`, `minimumFontScale`.

---

## 1. Dynamic Type / масштаб шрифта

Прототип нарисован в фиксированных px при системном масштабе 1.0. На устройстве пользователь может увеличить шрифт — дизайн обязан это пережить.

- **Включить масштабирование** везде, где это текст контента: `allowFontScaling={true}` (по умолчанию в RN — оставить).
- **Ограничить сверху:** `maxFontSizeMultiplier={1.4}` для заголовков и компактных карточек, `1.6` для основного текста. Без потолка крупные заголовки Instrument Serif ломают сетку.
- **Высота строки в множителях**, не в фиксированных px: `lineHeight` задавать как `fontSize * 1.2–1.4`, чтобы росла вместе с кеглем.
- **numberOfLines + ellipsis** для имён/видов/строк настроек (см. §3). Для заголовков экранов — `numberOfLines={2}`.
- **Не завязывать высоту контейнеров на фикс. px**, если внутри текст — `minHeight` вместо `height`.
- **Проверять при ×1.0, ×1.3, ×1.6** (iOS: Settings → Accessibility → Display → Larger Text; Android: Settings → Display → Font size).

## 2. Хит-таргеты

- Минимум **44×44 pt** (iOS) / **48×48 dp** (Android) для любого тапа.
- Иконки-кнопки (назад, 🔔, профиль, «+») визуально 40px — добавить `hitSlop={{top:6,bottom:6,left:6,right:6}}`.
- Чекбоксы/тумблеры/чипы — тап по всей строке-контейнеру, не только по контролу.
- Кнопки действий ухода не сжимать ниже таргета даже при длинном соседнем тексте (см. `Robustness.html` → «Имя и вид»).

## 3. Поведение под длинным контентом

| Элемент | Правило |
|---|---|
| Имя растения, вид | `numberOfLines={1}` + `ellipsizeMode="tail"` |
| Заголовок экрана | `numberOfLines={2}` |
| Реплика растения («…») | **не обрезать** — переносить свободно, контейнер растёт; это выразительный элемент |
| Числа-статистика | `fontVariant: ['tabular-nums']`; контейнер фикс. ширины; 4+ знака — `adjustsFontSizeToFit minimumFontScale={0.7}` |
| Ряд чипов/фильтров | `flexWrap: 'wrap'` + `gap`; горизонтальный скролл — только где задуман (фильтры истории 21) |
| Счётчики | склонение через `plural(n)` (см. `robustness-demos.jsx`): 1 растение / 2 растения / 5 растений |

**Тестовые данные для стресса:** имя `«Замиокулькас замиелистный пёстролистный»`, сад на 80+ растений, стрик `0` и `1247`, пустой дневник, реплика на 4 строки.

## 4. Скринридер (VoiceOver / TalkBack)

- **Каждому интерактивному элементу** — `accessibilityRole` (`button`, `switch`, `header`, `image`) и понятный `accessibilityLabel`.
- **Реплики растений** — это декоративно‑эмоциональный текст. Озвучивать осмысленно: label вида «Моника напоминает: полить, просрочено на 1 день», а не дословно кавычки. Эмодзи из label убирать.
- **Иконки-носители смысла** (просрочка, статус) дублировать текстом в label — нельзя полагаться только на цвет/эмодзи.
- **Состояния** (вкл/выкл тумблера, выбран чип) — через `accessibilityState={{ checked, selected, disabled }}`.
- **Группировать** карточку растения в один accessibility-элемент (`accessible={true}` на контейнере), чтобы свайп не читал по слову.
- **Порядок фокуса** — сверху вниз, слева направо; модалки/sheets перехватывают фокус (`accessibilityViewIsModal` на iOS).
- **Декоративные иллюстрации** растений — `accessibilityElementsHidden` / `importantForAccessibility="no"`, чтобы не зашумлять.

## 5. Контраст (WCAG AA)

- Основной текст — ≥ 4.5:1, крупный (≥24px/bold) — ≥ 3:1.
- Токены уже подобраны: `ink`/`inkSoft` проходят; `inkMute` поднят до ~3.7–4:1 (light `#7C8170`, dark `#7E8474`) — использовать только для третичных подписей ≥12px, не для важного текста.
- **Не кодировать смысл одним цветом** — просрочка это `terracotta` + текст «просрочено» + иконка.
- Проверять обе темы; dark — отдельный прогон (фон `surface` тёмный).

## 6. Прочее

- **Reduced motion:** `AccessibilityInfo.isReduceMotionEnabled()` → отключить spring/overshoot из `MOTION.md`, оставить мгновенную смену состояния.
- **Тач + клавиатура (внешняя):** поля ввода (имя растения, поиск, инвайт, таймзона) — корректный `returnKeyType`, фокус, `keyboardType`.
- **Локализация:** реплики растений и склонения переводимы (экран 38). Не склеивать строки конкатенацией — использовать ICU/i18n с плюрализацией.
- **Тёмная тема** следует системной (`useColorScheme()`) + ручной оверрайд в профиле.
